TradingView에서 피보나치 그리는 법:

1. QQQ 주봉(1W) 차트 열기
2. 왼쪽 도구바 → 세 번째 아이콘 (기울어진 선) → "피보나치 되돌림" 선택
3. 저점($270 부근, 2022년 10월)을 클릭 → 고점($540 부근, 2025년 초)까지 드래그
4. 자동으로 23.6%, 38.2%, 50%, 61.8% 수평선이 표시됨
5. 현재 가격이 어떤 선에 가까운지 확인

현재 상태 판단

현재 가격이 38.2%($437) 근처라면:

- 1차 지지선에 도달한 상태
- 여기서 양봉 출현 → 반등 시작 신호
- 이격도 -10% 이하 + RSI 30 이하와 함께 확인
- 3개 중 2개 충족 → 차트 근거 충족
38.2%를 종가로 이탈하면:

- 1차 지지 실패 → 50%($405)까지 열림
- $405에서도 못 버티면 → 61.8%($373)
- $373마저 깨지면 → 2023~2025 상승 추세 자체가 끝난 것
- 이때는 전략 재검토 필요
