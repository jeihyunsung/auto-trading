## 핵심 전략 프레임워크

### 4단계 전략 (자산제곱 기반)

| 전략 | 핵심 | 적용 시점 |
|------|------|----------|
| A. 묻어두기 | 지수 ETF 매수 후 장기 보유 | 기본 |
| B. 저점 집중 매수 | 다중 근거 기반 하락 구간 비중 확대 | 상시 적용 |
| C. 착한 레버리지 | 극단 저점 3신호 동시 충족 시 단기 2x 레버리지 | 10년에 2~3번 |
| D. 개별주 알파 | 지수 위에 초과수익 추구 | 경험 축적 후 |

### 저점 판단 5가지 근거 (전략 B)

근거가 겹칠수록 비중을 높인다:

```
□ 차트       — 이격도, RSI 과매도, 지지선(피보나치 되돌림 or 수평)
□ 유동성     — TGA 잔고 감소 추세, Fed 완화 방향
□ 정책       — 금리 인하 시그널, 재정 확대
□ 지정학     — 충격 이벤트 피크아웃
□ 모멘텀     — 선도 섹터 존재, 실적 서프라이즈
```

| 충족 근거 | 행동 | 비중 변화 |
|----------|------|----------|
| 0~1개 | 관망 | 현재 유지 |
| 2~3개 | 분할 매수 시작 | +10~20% |
| 4개 | 적극 매수 | +30% |
| 5개 | 최대 비중 | 상한까지 |

### 레버리지 진입 3신호 (전략 C)

3가지 동시 충족 시에만 진입. **QQQ 일봉 + 200 기간 이격도 기준.**

| 신호 | 기준 | 의미 |
|------|------|------|
| 이격도 (QQQ) | **-20% 이하** (극단은 -25%) | 평균회귀 압력 극대 |
| VIX | 35 이상 | 공포 극점, 매도 압력 소진 |
| 신규 실업수당 | 30만 명 미만 | 경제 기초체력 건재 |

규칙:
- 비중 최대 15%
- 목표 수익 20~30%에서 익절
- 단기만 (횡보장 진입 전 복귀)
- 익절 후 일반 ETF로 복귀

## 매수/매도 기준

### 모니터링 대상 지수

- **QQQ (나스닥 100)** — 본인 매수 대상, 매수/매도 타이밍
- **SPY (S&P 500)** — 시장 벤치마크, 전체 시장 심리 확인
- 두 지수가 **동시에 신호** → 강한 근거 / **한쪽만** → 약한 근거
- **차트 단위: 일봉(Daily) + 이격도 기간 200** 으로 통일 (주봉/단기 MA 금지)

### 매수 기준 — 이격도 (200일 MA 대비)

추세 자산은 양수 구간이 기본값. 기존 ±10% 기준은 QQQ/SPY에 맞지 않음.

| 구간 | QQQ | SPY | 행동 |
|------|-----|-----|------|
| 약한 관심 | **-5%** | **-3%** | 5가지 근거 체크 시작 |
| **1차 매수** | **-10%** | **-7%** | 2개+ 근거 충족 시 분할 매수 |
| 강한 매수 | **-15%** | **-12%** | 적극 매수 구간 |
| **극단 (전략 C)** | **-20% 이하** | **-15% 이하** | 레버리지 3신호 체크 |

### 매수 기준 — RSI (일봉 14일)

RSI는 자가 정규화 지표로 QQQ/SPY 동일 기준 사용.

| RSI | 행동 |
|-----|------|
| 30 이하 | 과매도 — 관심 |
| 25 이하 | 강한 과매도 — 매수 근거 |
| 20 이하 | 극단 — 적극 매수 |

### 매도 기준

| 유형 | 기준 |
|------|------|
| 목표 수익 도달 | +30% 시 1/3 매도 (분할 익절) |
| 과열 주의 | QQQ 이격도 +15% / SPY +10% → 추가 매수 중단 |
| 비중 축소 | QQQ 이격도 +20% / SPY +15%, RSI 70+ → 이익 1/3 실현 |
| 적극 매도 | QQQ 이격도 +25% / SPY +18%, RSI 80+ → 50% 비중 축소 |
| 근거 이탈 | 매수 근거가 2개 이하로 소멸 시 비중 축소 |
| 손절 | -15% (레버리지는 반드시 손절선 필수) |

### 비중 기준

| 시장 상태 | 주식 비중 | 현금 비중 |
|----------|----------|----------|
| 과열 | 60% | 40% |
| 정상 | 80% | 20% |
| 하락 (근거 3개+) | 90~95% | 5~10% |

## 타임라인: 2026.04 ~ 2027.06+

### Phase 1: 준비 기간 (2026.04 ~ 2026.06)

**목표: 기반 정리 + 모니터링 체계 구축**

```
□ 비상금 0.15억 CMA에서 분리 (별도 계좌 or 구분)
□ 빌라 양도세 비과세/감면 요건 정확히 확인
    - 보유 기간 기산일
    - 거주 요건 해당 여부
    - 감면 요건 충족 시점
□ 재개발 진행 단계 확인
    - 현재 단계: 조합설립 / 사업시행인가 / 관리처분
    - 다음 단계 예상 시점
□ 세입자 전세 만기일 확인 → 역전세 대비 계획
□ 모니터링 지표 세팅
    - TGA 잔고, VIX, 실업수당, RSI, 이격도
    - 주 1회 체크 루틴
□ ISA 계좌 내 포트폴리오 점검 (지수 ETF 중심인지 확인)
```

### Phase 2: 축적 기간 (2026.06 ~ 2027.06)

**목표: 금융자산 최대 축적 + 전략 B 실행**

```
매달 월급 잉여분 운용:

  시장 과열 시:  CMA에 전액 적립 (실탄 비축)
  시장 정상 시:  50~70% 지수 ETF 분할매수, 나머지 CMA
  시장 하락 시:  CMA 적립분 + 월급 잉여분 적극 투입

투자 가능 자산 운용:
  비상금:             0.15억 (절대 불가침)
  ISA 주식:           0.43억 (지수 ETF 중심 유지)
  CMA → 투자 전환:    0.28억 (시장 상태 보며 분할 투입)
  적금 만기 후:        0.17억 (동일 원칙 적용)

재개발/빌라 모니터링:
  □ 재개발 진행 상황 분기별 체크
  □ 빌라 시세 변동 확인
  □ 세입자 전세 만기 대응
```

### Phase 3: 전환 시점 (2027.06 ~ 2027.09)

**목표: 빌라 매도 판단 + 자산 재배분**

```
양도세 요건 충족 후 판단:

  판단 기준 1: 재개발 단계
    - 사업시행인가 전 → 매도 고려 (불확실성 높음)
    - 사업시행인가 후 → 시세 상승분 확보 후 매도 유력
    - 관리처분 단계   → 피크 근처, 매도 적기

  판단 기준 2: 시장 상태
    - 부동산 과열기 → 매도 적기
    - 부동산 침체기 → 매수자 부재, 매도 어려울 수 있음

  판단 기준 3: 금융시장 상태
    - 주식시장 하락 구간 → 매도 후 저점 매수 기회
    - 주식시장 과열 구간 → 서두를 필요 없음
```

### Phase 4: 재배분 실행 (빌라 매도 후)

**목표: 유동성 확보 + 전략 B/C 실행 가능한 구조 전환**

```
예상 가용 자산:
  빌라 매도 회수금:        ~2.5억 (시세에 따라 변동)
  14개월간 축적 금융자산:   ~1.0억+ (월급 적립분 포함)
  합계:                   ~3.5억+

목표 재배분:
  비상금 (CMA):                    0.30억  (8%)
  투자용 현금 대기 (CMA/단기채):     0.70억  (20%)
  코어 — 지수 ETF (ISA + 일반):     2.00억  (57%)
  위성 — 개별주/섹터 ETF:           0.50억  (15%)
  ───────────────────────────
  합계                             3.50억

재배분 실행 규칙:
  - 한 번에 전액 투입 금지
  - 3~6개월에 걸쳐 분할 매수
  - 시장 상태별 투입 속도 조절
  - 하락 구간이면 투입 가속, 과열이면 감속

월 고정비 변화:
  전세이자:      92만/월 (유지, 거주용)
  빌라 관련:     0원 (매도 완료)
  → 월급 잉여분 전액 투자 가능
```
