## 1. 차트

차트는 예측 도구가 아니라 "시장 참여자들이 어떤 상태인가"를 읽는 도구.

### 모니터링 대상 지수

**두 지수 동시 모니터링:**

| 지수 | 역할 | 비고 |
|------|------|------|
| **QQQ (나스닥 100)** | 매수 타이밍 | 주 매수 대상이므로 신호가 여기서 나와야 함 |
| **SPY (S&P 500)** | 시장 건강 체크 | 500개 기업 = 시장 전체 심리 대표 |
| (선택) IWM (Russell 2000) | 위험선호도 | 소형주 선/후행으로 전환기 포착 |

**판단 룰:**
- 두 지수 동시 과매도 → **강한 신호**, 적극 매수
- QQQ만 과매도, SPY 정상 → 기술주 이슈, 뉴스 확인 후 판단

### 이격도 (Disparity Index)

현재 가격이 이동평균선에서 얼마나 떨어져 있는지 보여주는 지표.

```
이격도 = (현재 가격 / 이동평균선) × 100 - 100

예시: 나스닥 200일 이동평균 = 18,000, 현재 가격 = 13,500
      이격도 = (13,500 / 18,000) × 100 - 100 = -25%
```

고무줄처럼 생각하면 된다. 평균에서 멀어질수록 되돌아오려는 힘이 강해진다.

> **주의:** 박스권 자산은 0으로 수렴하지만, **추세 자산(QQQ/SPY)은 양수 평균(+5~8%)으로 수렴**한다. 자세한 내용은 아래 "0 수렴 가정의 한계" 단락 참고.

#### 표준 설정: 일봉 + 200 기간

TradingView 기본값(14 기간)을 그대로 쓰면 안 된다. 반드시 아래 설정으로 변경:

```
차트 단위: 일봉 (D)
Disparity Index Length: 200
```

**왜 "일봉 + 200"인가:**
- 200일 ≈ 10개월 ≈ 실질적 "장기 추세선"
- 기관들이 매수/매도 기준으로 실제로 사용
- 단기 노이즈 제거
- Korean investment literature의 "이격도 -25% = 극단" 기준이 이걸 전제로 함

**주의: 기간 설정별 차이**

| 차트 | 기간 | 실제 MA | 쓸만한가? |
|------|------|---------|----------|
| **일봉** | **200** | 200일 ≈ 10개월 | ✅ **표준** |
| 일봉 | 50 | 50일 ≈ 2.5개월 | ❌ 너무 짧음 |
| **주봉** | **40~50** | 40~50주 ≈ 1년 | ✅ 보조 (일봉 200과 유사) |
| 주봉 | 200 | 200주 ≈ 4년 | ❌ 너무 길어서 항상 +18%+ 나옴 |
| 주봉 | 14 (기본) | 14주 ≈ 3개월 | ❌ 너무 짧음 |

**검증법:** 2022년 10월 저점 구간에서 값이 **-10% ~ -15%** 정도 나오면 올바른 설정.

#### "이격도 = 0 수렴" 가정의 한계와 추세 자산의 올바른 해석

이격도 지표를 처음 배울 때 흔히 "고무줄처럼 0(이동평균)으로 회귀한다"고 듣는다. **이건 박스권 자산 모델이고, QQQ/SPY 같은 추세 자산에는 맞지 않는다.**

**왜 0 수렴 가정이 틀렸는가:**

```
이격도 = (가격 - MA) / MA × 100

200일 MA는 가격을 후행 추적 (lagging)
→ 장기 우상향 추세에서는 가격이 항상 MA보다 위
→ 이격도가 구조적으로 양수 영역에 머무름
```

QQQ는 지난 2년간 200일 이격도가 한 번도 0 아래로 내려가지 않았다 (2024 미니 조정에서도 +3% 수준에서 멈춤). 0을 "정상값" 또는 "수렴 목표"로 보면 매수 기회를 영원히 놓친다.

**QQQ 200일 이격도 historical 분포 (10년 기준 추정):**

| 통계값 | 값 | 의미 |
|--------|-----|------|
| 10년 평균 (mean) | **+5 ~ +8%** | 진짜 "수렴 목표" |
| 중앙값 (median) | +6% | 정상 영역 |
| 0% 이하 기간 비중 | ~15% | 큰 조정장에서만 발생 |
| -10% 이하 기간 비중 | ~3% | 위기 수준 |
| -20% 이하 기간 비중 | ~1% | COVID/2022 약세장급 |

**올바른 mean-reversion 프레임:**

```
❌ 틀린 가정: 이격도 → 0 수렴 (박스권 모델)

✅ 맞는 가정: 이격도 → historical mean(+5~8%) 수렴 + 극단값에서 반전

추세장의 실제 dynamics:
  +20% (과열)   → 횡보/조정으로 +5% 회귀
  +5% (정상)    → 유지
  0% (드뭄)     → 반등으로 +5% 회귀  ← 이미 의미 있는 매수 신호
  -10% (위기)   → 강한 반등으로 +5% 회귀
```

**Percentile 기반 사고로 전환:**

절대값 임계(±10/±20)가 아니라 **historical 분포의 어느 위치인가**로 판단:

| 신호 | QQQ 이격도 | percentile | 빈도 |
|------|-----------|-----------|------|
| 극단 과열 | +25% 이상 | 상위 1~3% | 5~10년에 1~2회 |
| 과열 | +20% | 상위 5% | 연 1회 미만 |
| 단기 과열 | +15% | 상위 15~20% | 연 2~3회 |
| **정상 영역** | **+5 ~ +12%** | **중앙 50%** | **대부분의 기간** |
| 약한 관심 | 0 ~ +3% | 하위 20% | 연 1~2회 |
| **저평가 신호** | **0%** | **하위 15%** | **2~3년에 1회** |
| 강한 매수 | -10% | 하위 3% | 5년에 1~2회 |
| 극단 (전략 C) | -20% 이하 | 하위 1% | 5~10년에 1~2회 |

**핵심 시사점:**

1. **0%는 "정상"이 아니라 "하위 15% 분위수"** — QQQ가 200일선을 터치하는 것 자체가 의미 있는 매수 이벤트.
2. **수렴 목표는 0이 아닌 historical mean(~+5~8%)** — 차트에서 이격도가 "정상으로 돌아갔다"는 건 0이 아니라 +5% 부근.
3. **양수 = 무조건 비싼 것이 아님** — +5~+12%는 정상 영역. +15% 넘어야 단기 과열로 본다.
4. **추세 자산과 박스권 자산을 구분** — 같은 ±10% 기준을 양쪽에 적용하면 추세 자산에서는 절대 못 사고, 박스권에서는 너무 자주 산다.

#### 실전 기준값 (추세 자산 — QQQ/SPY)

**중요: 기존 ±10% 기준은 박스권 자산용이라 QQQ/SPY에는 맞지 않음.** 추세 자산은 양수 구간이 기본값(historical mean ~+5~8%)이므로 양쪽 기준을 모두 비대칭으로 잡아야 한다. 매수 신호는 자주 안 오고, 과열은 +15% 이상부터.

**QQQ (일봉 200 MA 기준):**

| 구간 | 이격도 | percentile | 빈도 | 행동 |
|------|--------|-----------|------|------|
| **저평가 신호** | **0%** | 하위 15% | 2~3년에 1회 | 관심 시작, 근거 체크 |
| 약한 관심 | **-5%** | 하위 7% | 연 1회 이하 | 다른 근거 같이 체크 |
| **1차 매수** | **-10%** | 하위 3% | 5년에 1~2회 | 근거 2개+ 충족 시 분할 매수 |
| 강한 매수 | **-15%** | 하위 1~2% | 5~7년에 1회 | 적극 매수 구간 |
| **극단 (전략 C)** | **-20% 이하** | 하위 1% | 5~10년에 1~2회 | 레버리지 3신호 체크 |
| 정상 영역 | +5 ~ +12% | 중앙 50% | 대부분 기간 | 자동이체만 진행 |
| 주의 | +15% | 상위 15~20% | 연 2~3회 | 추가 매수 중단 |
| 비중 축소 | +20% | 상위 5% | 연 1회 미만 | 이익 1/3 실현 |
| 적극 매도 | +25% 이상 | 상위 1~3% | 5~10년에 1~2회 | 비중 50%까지 축소 |

**SPY (QQQ보다 변동성 낮음 → 기준도 낮춤. historical mean ~+3~5%):**

| 구간 | 이격도 | percentile | 행동 |
|------|--------|-----------|------|
| **저평가 신호** | **-1%** | 하위 15% | 관심 시작 |
| 약한 관심 | **-3%** | 하위 7% | 근거 체크 |
| **1차 매수** | **-7%** | 하위 3% | 분할 매수 |
| 강한 매수 | **-12%** | 하위 1~2% | 적극 매수 |
| **극단 (전략 C)** | **-15% 이하** | 하위 1% | 레버리지 체크 |
| 정상 영역 | +3 ~ +8% | 중앙 50% | 자동이체만 진행 |
| 주의 | +10% | 상위 15~20% | 추가 매수 중단 |
| 비중 축소 | +15% | 상위 5% | 이익 실현 |
| 적극 매도 | +18% 이상 | 상위 1~3% | 적극 축소 |

**확인 방법:**
- TradingView: https://www.tradingview.com/chart/
- 심볼: `NASDAQ:QQQ` 또는 `AMEX:SPY` 입력
- **반드시 차트 단위를 일봉(D)으로 설정**
- 상단 "지표(Indicators)" 클릭 → "Disparity Index" 검색
- 커뮤니티 스크립트에서 "Disparity Index" 선택
- **설정(톱니바퀴) → Length 를 14에서 200으로 변경** (필수)
- 대안: 주봉을 쓰려면 Length를 40~50으로 설정

### RSI (Relative Strength Index, 상대강도지수)

최근 14일간 상승폭 vs 하락폭의 비율. "너무 많이 올랐나, 너무 많이 내렸나"를 0~100으로 표현.

| RSI | 상태 | 의미 |
|-----|------|------|
| 0~20 | 극단적 과매도 | 팔 사람은 거의 다 팔았다 |
| 20~30 | 과매도 | 관심 구간 |
| 30~70 | 중립 | 특별한 신호 없음 |
| 70~80 | 과매수 | 단기 조정 가능 |
| 80~100 | 극단적 과열 | 하락 가능성 |

**확인 방법:**
- TradingView: https://www.tradingview.com/chart/?symbol=NASDAQ:QQQ
- 상단 "지표(Indicators)" 클릭 → "RSI" 검색
- 기본 내장 지표 "Relative Strength Index" 선택 (기본 기간: 14일)
- 차트 하단에 RSI 라인이 표시됨
- 30 이하 / 70 이상 구간에 자동으로 음영 표시

### 주요 지지선

가격이 하락할 때 매수세가 몰려 반등하는 가격대. 두 가지 유형이 있다.

#### 유형 1: 수평 지지선 (횡보/반등 구간이 있는 차트)

과거에 가격이 2회 이상 비슷한 수준에서 반등한 가격대.

```
예시: 나스닥이 15,000에서 3번 반등 → 15,000이 지지선
      그 가격대에서 "싸다"고 판단하는 매수자가 많기 때문
```

- 현재 가격이 지지선 **±2% 이내**면 "도달"로 판단
- 지지선에서 **양봉 출현** → 반등 시작 신호
- 지지선을 **종가 기준으로 이탈** → 그 지지선은 무효, 다음 지지선 확인

#### 유형 2: 피보나치 되돌림 (쭉 올라간 차트)

QQQ처럼 뚜렷한 반등 지점 없이 장기 상승한 차트에서는 수평 지지선이 거의 없다.
이런 경우 **피보나치 되돌림(Fibonacci Retracement)** 으로 지지 가격대를 추정한다.

```
피보나치 되돌림 = 상승폭의 일정 비율만큼 되돌아갈 때의 가격

계산법:
  상승 시작점(저점): A
  고점: B
  상승폭: B - A

  38.2% 되돌림 = B - (B - A) × 0.382  ← 1차 지지
  50.0% 되돌림 = B - (B - A) × 0.500  ← 2차 지지
  61.8% 되돌림 = B - (B - A) × 0.618  ← 3차 지지 (여기 깨지면 상승 추세 자체 의심)
```

| 되돌림 비율 | 의미 | 판단 |
|------------|------|------|
| **38.2%** | 건강한 조정, 상승 추세 유지 | 관심 구간 |
| **50.0%** | 상승분의 절반 반납 | 적극 관심 |
| **61.8%** | 황금비율, 마지막 지지선 | 여기서 반등 못 하면 추세 전환 |

**확인 방법:**
- TradingView: https://www.tradingview.com/chart/?symbol=NASDAQ:QQQ
- **피보나치 되돌림 그리기:**
  1. 왼쪽 도구바 → 세 번째 아이콘(기울어진 선) 클릭 → "피보나치 되돌림" 선택
  2. **상승 시작점(저점)** 에서 클릭 → **고점**까지 드래그
  3. 자동으로 38.2%, 50%, 61.8% 수평선이 표시됨
  4. 현재 가격이 어떤 선에 근접한지 확인
- **이동평균선 (동적 지지선):**
  1. 상단 "Indicators" → "MA" 검색 → Moving Average 추가
  2. 기간을 **200일**로 설정
  3. 가격이 200일선에 닿으면 = 이격도 0%, 동적 지지선 도달
  4. 사실상 이격도와 같은 개념 — 이격도가 지지선 역할을 대체

#### 어떤 유형을 쓸지 판단

```
차트에 뚜렷한 반등 지점이 2회 이상 보이는가?
├── YES → 수평 지지선 사용
└── NO  → 피보나치 되돌림 + 200일 이동평균 사용
```

> **참고:** 장기 상승 차트에서는 이격도(200일선 대비)가 사실상 지지선의 역할을 한다.
> 이격도 -10% = 200일선 아래 10% = 동적 지지선 아래로 진입한 상태.

#### 투자 기간별 지지선

**같은 가격, 다른 해석.** 홀딩 기간에 따라 그려야 할 피보나치 범위가 달라진다.

**지지선 그릴 때 필요한 3가지 요소:**

1. **시작점 (저점)** — 의미 있는 저점. 단순히 낮은 곳이 아니라 시장이 공포에 빠졌다가 반등한 지점 (약세장 바닥, 거래량 폭발 후 반등 지점).
2. **끝점 (고점)** — 의미 있는 고점. 해당 구간의 역사적 신고가 또는 과열 피크.
3. **차트 단위** — 시작점과 끝점이 보이는 **가장 큰 단위**를 선택.

**투자 기간별 매칭:**

| 투자 기간 | 홀딩 기간 | 차트 단위 | 시작점 | 끝점 | 대상 움직임 |
|----------|----------|----------|--------|------|------------|
| 초단기 | 며칠 | 시간봉/일봉 | 최근 며칠 저점 | 최근 며칠 고점 | 5% 이내 |
| 단기 | 몇 주 | 일봉 | 최근 1~3개월 저점 | 최근 고점 | 5~15% |
| 중기 | 몇 달 ~ 1년 | 일봉/주봉 | 최근 6개월~1년 저점 | 최근 고점 | 15~30% |
| **장기** | **1년+** | **주봉/월봉** | **주요 약세장 저점 (2022, 2020 등)** | **역사적 고점** | **30%+** |

**전략별 매칭 (본 문서의 투자 전략 기준):**

| 전략 | 홀딩 | 쓸 피보나치 |
|------|------|-----------|
| 전략 A (지수 묻어두기) | 평생 | 장기 피보나치 확인만 (팔지 않음) |
| **전략 B (저점 집중 매수)** | 수년 | **장기 피보나치 필수** + 중기 보조 |
| 전략 C (레버리지) | 수개월 | 장기 피보나치 61.8% 이상 극단 구간 |
| 전략 D (개별주 알파) | 가변 | 중기 피보나치 |

**QQQ 같은 가격, 3가지 관점 예시:**

```
현재 가격 $614일 때

초단기 (일봉, 최근 1개월):  $580 → $636
  → 38.2% = $615, 50% = $608    → "고점 근처, 매도 고려"

중기 (일봉, 최근 6개월):     $430 → $636
  → 38.2% = $557, 50% = $533    → "새로 매수 타이밍 아님"

장기 (주봉, 2022~2025):      $267 → $636
  → 38.2% = $495, 50% = $452, 61.8% = $408
  → "고점에서 살짝 내려온 정도, 매수 구간 멀음"
```

**핵심 원칙:**

1. **"내가 얼마나 오래 보유할지"부터 정한다** — 1년 뒤 쓸 돈이면 단기, 5년 뒤면 장기 피보나치.
2. **Top-down 접근** — 월봉/주봉으로 큰 그림 먼저, 일봉으로 타이밍 확인.
3. **컨플루언스(Confluence) 지지** — 여러 시간대 레벨이 겹치면 강력한 신호. 예: 장기 38.2% ≈ 200일 이평 ≈ 주요 수평선 → 반등 확률 높음.

#### ATH(최고가) 구간에서의 지지선 활용

QQQ/SPY는 추세 자산이라 신고가 갱신 구간이 흔하다. 이때 "현재가가 어느 피보나치 레벨인가"를 매주 체크하는 건 의미 없다 — 모든 레벨보다 한참 위에 있어서 답이 항상 같다.

**ATH 구간 (현재가가 최고가 또는 ATH -5% 이내) 처리법:**

```
□ "현재 레벨 체크"는 스킵 → 매수 신호 0개 확정
□ 대신 "다음 매수 가격대" 미리 메모:
    · 38.2% 가격: $______
    · 50% 가격:   $______
    · 61.8% 가격: $______
□ 그 가격까지의 하락률(%)도 함께 메모
□ 이격도/RSI가 메인 신호, 피보나치는 백그라운드 시나리오
```

**왜 이렇게 하나:**

| 일반 구간 (조정 진행 중) | ATH 구간 |
|----------------------|---------|
| 피보나치 = 메인 매수 신호 | 피보나치 = 백그라운드 시나리오 |
| 매주 "어느 레벨 도달?" 체크 | 매주 체크 불필요 |
| 이격도/RSI는 보조 | **이격도/RSI가 메인 신호** |
| 5가지 근거 + 지지선 같이 봄 | 5가지 근거만 우선 |

**시나리오 메모의 가치:**

ATH에서 막상 -10% 조정이 오면 "여기서 사야 하나?" 망설이게 된다. 미리 가격대를 적어두면 감정 개입을 줄일 수 있음:

```
예: 2026-04 QQQ ATH $636 시점에 미리 메모
    · 다음 매수가 1차: $545 (38.2% 되돌림, ATH -14%)
    · 다음 매수가 2차: $452 (50% 되돌림, ATH -29%)
    · 다음 매수가 3차: $408 (61.8% 되돌림, ATH -36%)

→ 한 달 후 $560까지 빠지면 "1차 가격대 도달"로 즉시 인지.
```

**ATH 갱신 시 메모 업데이트:**

신고가가 계속 갱신되면 피보나치 끝점도 함께 올라가야 한다. **분기 1회 또는 신고가 +5% 갱신 시** 메모를 다시 계산.

#### 매수/매도 판단법

지지선 하나로만 사고팔지 않는다. **접근 → 터치 → 확인** 3단계와 **5가지 근거 체크리스트**를 함께 본다.

##### 매수 3단계

```
[단계 1] 접근 (지지선 ±3% 이내)
  → "관심" 모드, 아직 매수 X
  → 뉴스/유동성/VIX 등 다른 근거 체크 시작

[단계 2] 터치 (지지선 ±1% 이내)
  → 1차 매수 고려
  → 근거 체크리스트 2개 이상 충족 시만 실행

[단계 3] 확인 (지지선에서 반등 검증)
  → 다음 일봉/주봉 양봉 종가 마감
  → 거래량 평소 대비 증가
  → 2차 매수 (추가 비중)
```

##### 지지선별 분할 매수 (장기 피보나치 기준)

```
총 투자금을 100%로 보고:

□ 장기 38.2% 터치 + 근거 2개+
    → 1차 매수: 전체의 20~30% ("조금만, 더 내려갈 수도")

□ 장기 50% 터치 + 근거 3개+
    → 2차 매수: 전체의 30~40% ("진짜 싸다, 추가")

□ 장기 61.8% 터치 + 근거 4개+
    → 3차 매수: 전체의 30~40% ("거의 마지노선")
    → 여기서 전략 C 레버리지도 검토

□ 61.8% 깨지면
    → 매수 중단, 상승 추세 자체 의심
    → 전략 재검토
```

##### 매도 2가지 기준

**기준 1: 지지선 붕괴 (손절/비중 축소)**

```
□ 일봉/주봉 종가가 지지선 아래로 마감
    → 단순 터치(꼬리)가 아니라 "종가 마감 이탈"이 기준

□ 지지선 깨진 후 재돌파 실패
    → "깨진 지지선은 저항선이 된다" (역할 전환)

□ 손절 기준: 매수가 대비 -15%
    → 강제 룰, 감정 배제. 레버리지는 필수 손절.
```

**기준 2: 저항선 도달 (익절)**

상승 시에는 피보나치를 반대로 그려 저항선 설정:

```
□ 원래 고점 회복 (100% 되돌림) 시: 1/3 익절
□ 전고점 돌파 후 +20% 시:         추가 1/3 익절
□ 남은 1/3은 장기 보유 (전략 A)
```

##### 케이스별 실전 매뉴얼

| 케이스 | 상황 | 판단 | 행동 |
|--------|------|------|------|
| A (이상적) | 지지선 터치 → 양봉 → 거래량 증가 | 진짜 반등 | **1차 매수 실행**, 손절선 -5% 아래 설정 |
| B (애매) | 지지선 터치 → 음봉 | 반등 실패 | **매수 보류**, 다음 지지선 대기 |
| C (하락 지속) | 지지선 종가 이탈 | 지지 실패 | **매수 중단**, 다음 지지선을 새 기준으로 |
| D (긍정적) | 지지선 위에서 횡보 | 축적 구간 | **1차 매수 가능**, 상단 돌파 시 추가 매수 |

##### 거래량 확인 (매우 중요)

지지선에서 반등은 **거래량과 함께** 봐야 진짜인지 구분된다.

| 조합 | 의미 | 신뢰도 |
|------|------|--------|
| 터치 + 양봉 + 거래량 증가 | 매수 세력 실제 유입 | ✅ 진짜 반등 |
| 터치 + 양봉 + 거래량 평소 수준 | 기술적 반등 가능성 | ⚠️ 재하락 위험 |
| 터치 + 양봉 + 거래량 급감 | 매수도 매도도 없음 | ❌ 횡보하다 재하락 가능 |

##### 지지선 기반 5가지 원칙

```
1. 접근 ≠ 매수 (±3% 이내는 "관심", 아직 안 삼)

2. 터치만으로 안 산다 (반등 확인 후 매수)
   → 양봉 종가 마감 + 거래량 증가

3. 분할 매수 필수 (한 지지선 한 번에 전액 X)
   → 38.2% / 50% / 61.8% 나눠서

4. 종가 이탈이 기준 (intraday 터치는 노이즈)
   → 일봉 종가가 지지선 아래 → 진짜 이탈

5. 지지선 + 5가지 근거 같이 (지지선만으로는 부족)
   → 차트 근거 3개 중 2개+ / 전체 5개 중 2개+
```

##### 종합 체크리스트

```
[ 매수 체크 ]
□ 차트 단위 확인 (장기면 주봉)
□ 장기 피보나치 그리기 (2022 저점 → 최근 고점)
□ 현재 가격이 38.2% / 50% / 61.8% 어디에?
□ 지지선 ±3% 이내? (관심 단계)
□ 지지선 ±1% 이내 + 양봉 + 거래량 증가? (매수 단계)
□ 이격도/RSI도 과매도?
□ 5가지 근거 중 몇 개 충족?
□ 분할 매수 계획 수립

[ 매도 체크 ]
□ 일봉/주봉 종가가 지지선 아래로 마감?
□ 거래량 동반 하락?
□ 재돌파 시도 실패?
□ 매수가 대비 -15% 도달?
→ YES 2개+ → 비중 축소 / 손절 실행
```

## 2. 유동성

시장에 돈이 얼마나 풀려 있고, 앞으로 더 풀릴 건지 줄어들 건지. 주가는 결국 돈의 흐름을 따른다.

### TGA (Treasury General Account, 재무부 일반계정)

미국 정부의 "통장 잔고". 정부가 돈을 쓰면 시중에 유동성이 공급된다.

```
TGA 감소 = 정부가 돈을 쓰는 중 = 시중에 돈이 풀림 = 주가 상승 압력
TGA 증가 = 정부가 돈을 모으는 중 = 시중에서 돈이 빠짐 = 주가 하락 압력
```

**확인 방법:**
- FRED: https://fred.stlouisfed.org/series/WTREGEN
- 시리즈: WTREGEN — "U.S. Treasury, General Account, Weekly"
- 직접 접속하면 차트가 바로 보임
- "Edit Graph" 클릭해서 날짜 범위 조정 가능
- 업데이트: 매주 수요일
- 무료, 회원가입 불필요

**읽는 법:**
- 차트가 우하향 = TGA 감소 중 = 유동성 공급 = 긍정적
- 차트가 우상향 = TGA 증가 중 = 유동성 회수 = 부정적

### Fed 대차대조표 (Balance Sheet)

Fed가 보유한 자산의 총규모. Fed가 채권을 사면 시중에 돈이 풀리고, 팔면 돈이 빠진다.

```
대차대조표 증가 = 양적완화(QE), 돈을 푸는 중 = 주가 상승 압력
대차대조표 감소 = 양적긴축(QT), 돈을 거두는 중 = 주가 하락 압력
```

**확인 방법:**
- FRED: https://fred.stlouisfed.org/series/WALCL
- 시리즈: WALCL — "Assets: Total Assets (Less Eliminations from Consolidation)"
- 업데이트: 매주 수요일
- 무료, 회원가입 불필요

### 역레포 (Reverse Repo, RRP)

금융기관들이 남는 현금을 Fed에 하루짜리로 맡기는 것.

```
역레포 잔고 감소 = 돈이 시장으로 이동 중 = 주가 상승 압력
역레포 잔고 증가 = 돈이 시장에서 빠짐 = 주가 하락 압력
역레포 0에 수렴 = 더 이상 풀 돈이 없음 = 유동성 공급 한계
```

**확인 방법:**
- FRED: https://fred.stlouisfed.org/series/RRPONTSYD
- 시리즈: RRPONTSYD — "Overnight Reverse Repurchase Agreements"
- 뉴욕 연준: https://www.newyorkfed.org/markets/desk-operations/reverse-repo
  - 일별 RRP 운용 결과, 참여 기관 수, 총 금액 확인 가능
- 무료, 회원가입 불필요

### 유동성 종합 판단

```
TGA 감소 + Fed 대차대조표 확대 + 역레포 감소
= 세 곳에서 돈이 풀리는 중 → 유동성 체크 충족

TGA 증가 + Fed 대차대조표 축소 + 역레포 증가
= 세 곳에서 돈이 빠지는 중 → 유동성 불리
```

## 3. 정책

정부와 중앙은행이 앞으로 경제를 어떤 방향으로 끌고 가려 하는가.

### 금리 방향 — CME FedWatch Tool

시장 참여자들이 예상하는 다음 FOMC 회의에서의 금리 변동 확률.

| FedWatch 확률 | 해석 |
|---------------|------|
| 70% 이상 인하 예상 | 시장은 인하를 기정사실화 |
| 30~70% | 불확실, 데이터에 따라 변동 |
| 30% 미만 인하 예상 | 인하 가능성 낮음 |

**확인 방법:**
- CME FedWatch: https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html
- 접속하면 바로 다음 FOMC 회의별 금리 확률이 막대그래프로 표시
- 각 회의 날짜를 클릭하면 상세 확률 분포 확인 가능
- 무료, 회원가입 불필요

### FOMC 일정 및 회의록

Fed가 금리를 결정하는 회의. 연 8회 개최.

**확인 방법:**
- FOMC 일정: https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm
  - 올해/내년 회의 날짜, 성명서, 회의록 링크 모두 제공
- FOMC 회의록: https://www.federalreserve.gov/monetarypolicy/fomc_minutes.htm
  - 회의 3주 후 공개. 위원들의 논의 내용, 경제 전망 포함
- 무료

### Fed 점도표 (Dot Plot)

Fed 위원들(18명)이 각자 예상하는 미래 금리를 점으로 표시한 차트. 분기별(3, 6, 9, 12월 회의) 공개.

```
점들이 아래에 몰림 = 위원들이 금리 인하를 예상 = 완화적
점들이 위에 몰림 = 위원들이 금리 인상/유지 예상 = 긴축적
```

**확인 방법:**
- Fed 공식: https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm
  - "Projection Materials" 링크가 있는 회의 → PDF 다운로드
  - "Summary of Economic Projections (SEP)" 안에 점도표 포함
- CME에서도 시각화 제공: FedWatch 페이지 내 Dot Plot 탭
- 무료

### 재정 정책 확인

```
재정 확대 = 인프라 투자, 보조금, 감세 → 경제에 돈 풀림 → 호재
재정 긴축 = 지출 삭감, 증세 → 경제 위축 → 악재
```

**확인 방법:**
- 뉴스 기반으로 확인 (정량 지표가 아닌 정성 판단)
- Reuters, Bloomberg, CNBC 등에서 미국 재정 정책 뉴스 추적
- 주요 키워드: infrastructure bill, stimulus, tax cut, spending cut, debt ceiling

## 4. 지정학

전쟁, 무역 갈등, 제재 등 정치적 이벤트의 시장 심리 충격.

### 피크아웃 판단법

악재 자체가 끝나지 않아도, 시장이 그 악재에 무감각해지는 순간이 피크아웃.

| 신호 | 의미 |
|------|------|
| 같은 뉴스에 주가가 더 이상 빠지지 않는다 | 악재 소화 중 |
| VIX가 고점 찍고 내려오기 시작 | 공포 피크아웃 |
| 안전자산(금, 달러, 국채)에서 돈이 빠진다 | 위험자산으로 복귀 시작 |
| 협상/회담 뉴스 등장 | 최악은 지나가는 중 |

### VIX (공포지수)

S&P 500 옵션의 내재 변동성. 시장의 공포 수준을 숫자로 표현.

| VIX | 상태 |
|-----|------|
| 12 이하 | 극단적 안정 (오히려 과열 주의) |
| 12~20 | 정상 |
| 20~30 | 불안 |
| 30~35 | 높은 공포 |
| 35 이상 | 극단적 공포 → 레버리지 진입 신호 중 하나 |

**확인 방법:**
- TradingView: https://www.tradingview.com/chart/?symbol=CBOE:VIX
- CBOE (공식): https://www.cboe.com/tradable_products/vix/
- Google에 "VIX" 검색하면 실시간 값 표시
- 무료

### Fear & Greed Index (공포/탐욕 지수)

CNN이 7가지 지표를 종합해서 0~100으로 시장 심리를 표현.

```
0~25:  극단적 공포 (Extreme Fear) → 반등 가능성 관심
25~45: 공포 (Fear)
45~55: 중립 (Neutral)
55~75: 탐욕 (Greed)
75~100: 극단적 탐욕 (Extreme Greed) → 과열 주의
```

**확인 방법:**
- CNN: https://edition.cnn.com/markets/fear-and-greed
- 접속하면 바로 현재 지수 + 구성 7가지 지표 확인 가능
- 7가지 구성: 시장 모멘텀, 주가 강도, 주가 폭, 풋/콜 비율, 정크본드 수요, 시장 변동성, 안전자산 수요
- 무료, 회원가입 불필요

## 5. 모멘텀/섹터

어떤 분야가 돈을 끌어당기고 있는가.

### 섹터 퍼포먼스

```
선도 섹터가 명확하다 = 돈의 방향이 있다 = 시장 건강
모든 섹터가 골고루 오른다 = 후반부일 수 있음 = 과열 주의
선도 섹터 없이 횡보 = 방향성 부재 = 관망
선도 섹터가 무너진다 = 시장 전체 하락 신호
```

**확인 방법:**
- Finviz 섹터 성과: https://finviz.com/groups.ashx?g=sector&v=140&o=-perf1w
  - 섹터별 1일/1주/1개월/3개월/6개월/1년 수익률 비교
  - 컬럼 헤더 클릭으로 정렬 가능
- Finviz 히트맵: https://finviz.com/map.ashx
  - 시장 전체를 섹터별 시각 히트맵으로 표시
  - 빨강 = 하락, 초록 = 상승, 크기 = 시가총액
- TradingView 섹터: https://www.tradingview.com/markets/us/sectorandindustry-performance/
- 무료

### 실적 서프라이즈 (Earnings Surprise)

기업 실적이 시장 예상(컨센서스)을 초과했는지 여부.

```
다수 기업 서프라이즈 = 경제가 예상보다 좋다 = 상승 근거
다수 기업 실적 미스 = 경제가 예상보다 나쁘다 = 하락 근거
가이던스 상향 = 앞으로도 좋다 = 강한 호재
가이던스 하향 = 실적은 좋았지만 앞으로 나쁘다 = 주의
```

실적 시즌: 1월, 4월, 7월, 10월에 집중 확인.

**확인 방법:**
- Yahoo Finance 실적 캘린더: https://finance.yahoo.com/calendar/earnings/
  - 날짜별 실적 발표 기업, 예상 EPS vs 실제 EPS 확인
- Finviz 캘린더: https://finviz.com/calendar.ashx
- Earnings Whispers: https://www.earningswhispers.com/calendar
  - 가장 기대되는 실적 발표를 시각적으로 표시
- 무료

## 6. 경제 기초체력 지표

레버리지 진입(전략 C) 판단과 전반적 경기 상태 확인용.

### 신규 실업수당 (Initial Jobless Claims)

매주 발표. 새로 실업급여를 신청한 사람 수.

```
30만 명 미만 = 고용시장 건재 = 경기침체 아닌 심리적 과매도
30만 명 이상 지속 = 고용 악화 신호 = 실제 경기침체 가능성
```

**확인 방법:**
- FRED: https://fred.stlouisfed.org/series/ICSA
- 시리즈: ICSA — "Initial Claims"
- 업데이트: 매주 목요일 오전 (미국 동부시간)
- 계속 실업수당: https://fred.stlouisfed.org/series/CCSA
- 무료, 회원가입 불필요

### CPI (Consumer Price Index, 소비자물가지수)

물가 상승률. Fed의 금리 결정에 가장 큰 영향을 미치는 지표.

```
CPI 하락 추세 = 인플레이션 둔화 = 금리 인하 가능성 = 주식 호재
CPI 상승 추세 = 인플레이션 가속 = 금리 인상 가능성 = 주식 악재
```

**확인 방법:**
- FRED (CPI 전체): https://fred.stlouisfed.org/series/CPIAUCSL
- BLS (공식): https://www.bls.gov/cpi/
- 발표 일정: https://www.bls.gov/schedule/news_release/cpi.htm
- 업데이트: 월 1회 (보통 매월 10~15일)
- 무료

### PMI (Purchasing Managers' Index, 구매관리자지수)

기업 구매 담당자에게 물어본 경기 체감 지수.

```
50 이상 = 경기 확장
50 미만 = 경기 수축
50 근처에서 방향이 중요 (상승 추세인지 하락 추세인지)
```

**확인 방법:**
- ISM (공식): https://www.ismworld.org/supply-management-news-and-reports/reports/ism-report-on-business/
  - 제조업 PMI + 서비스업 PMI
- Investing.com: https://www.investing.com/economic-calendar/ism-manufacturing-pmi-173
  - 예상치 vs 실제치 비교, 과거 데이터 포함
- 업데이트: 월 1회 (매월 첫 영업일)
- 무료 (ISM 헤드라인 숫자는 무료, 상세 리포트는 유료)

## 전략 C 레버리지 진입 3신호 확인법

3가지가 **동시에** 충족될 때만 진입. 10년에 2~3번.

| 신호 | 기준 (QQQ 기준) | 확인 소스 |
|------|------|----------|
| 이격도 | **일봉 200 MA 대비 -20% 이하** (COVID급 극단은 -25%) | TradingView — Disparity Index |
| VIX | 35 이상 | TradingView — CBOE:VIX |
| 신규 실업수당 | 30만 미만 | FRED — ICSA 시리즈 |

```
□ QQQ 이격도 -20% 이하? (일봉 + 200 기간)  → TradingView 확인
□ VIX 35 이상?                               → TradingView 또는 Google "VIX" 검색
□ 실업수당 30만 미만?                         → FRED ICSA 최신 데이터 확인

3개 모두 충족 → 레버리지 진입 고려 (비중 15% 이내, 익절 20~30%)
```

**참고:** 기존 전략 문서의 "이격도 -25%"는 2020 COVID / 2008 금융위기급 극단. 실전 레버리지 진입 기준은 **-20%**가 더 현실적. QQQ 2022년 저점도 약 -20% 수준이었음.
