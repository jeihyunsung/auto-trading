# 월급 적립식 투자 운영 가이드

작성일: 2026-04-18

월급 잉여 500만원/월 가정. 시장 상태에 따라 매수/적립 비율을 조정하는 적극적 적립식 투자 운영법.

---

## 매주 회고 체크리스트 (주말 30분)

매주 일요일 또는 토요일 30분 투자해서 시장 상태를 체크하고 다음 한 주의 적립 방향을 결정한다.

### 0. 회고 (5분)

```
[ 지난 주 회고 ]
□ 지난 주 결정한 적립 방향대로 실행했는가? (YES / NO)
   - 자동이체 그대로 진행 / 수동 조정 / 임시 중단
□ 시장이 예상대로 움직였는가?
□ 새로 발생한 이벤트는? (FOMC, 실적, 지정학)
□ 실수/감정적 매매는 없었는가?
```

### 1. 차트 지표 (10분) — TradingView

**설정: 일봉(D) 차트 + Disparity Index Length 200 + RSI 14**

> **중요:** QQQ/SPY는 추세 자산이라 200일 이격도가 0이 아닌 **양수 평균(QQQ ~+5~8%, SPY ~+3~5%)** 으로 수렴한다. "+5~+12%는 정상"이고 "0% 이미 하위 15% 분위수의 매수 신호"다. 절대값보다 **historical 분포의 위치(percentile)** 로 판단하는 게 맞다.

```
[ QQQ 체크 ]
□ 현재 가격: $______
□ 이격도 (200일): _____%
   ├─ +25% 이상: 극단 과열 (상위 1~3%, 적극 매도)
   ├─ +20%:      과열 (상위 5%, 비중 축소)
   ├─ +15~+20%: 단기 과열/주의 (상위 15~20%, 매수 중단)
   ├─ +5~+12%:  정상 영역 (중앙 50%, historical mean)
   ├─ 0~+3%:    약한 관심 (하위 20%)
   ├─ 0%:       저평가 신호 (하위 15%, 200MA 터치 = 의미 있는 이벤트)
   ├─ -5%:      관심 강화 (하위 7%)
   ├─ -10%:     1차 매수 (하위 3%, 5년에 1~2회)
   ├─ -15%:     강한 매수 (하위 1~2%)
   └─ -20% 이하: 극단/전략 C (하위 1%, 5~10년에 1~2회)
□ RSI (14일): _____
   ├─ 80+: 극단 과열
   ├─ 70~80: 과매수 (단기 부담)
   ├─ 30~70: 중립
   ├─ 20~30: 과매도 (관심)
   └─ 20 이하: 극단 과매도

[ SPY 체크 ]
□ 현재 가격: $______
□ 이격도 (200일): _____%
   ├─ +18% 이상: 극단 과열
   ├─ +15%:      과열 (비중 축소)
   ├─ +10%:      단기 과열 (매수 중단)
   ├─ +3~+8%:   정상 영역 (historical mean)
   ├─ -1%:       저평가 신호
   ├─ -3%:       관심 강화
   ├─ -7%:       1차 매수
   ├─ -12%:      강한 매수
   └─ -15% 이하: 극단/전략 C
□ RSI (14일): _____

[ 다이버전스 체크 ]
□ QQQ와 SPY 같은 방향?
   ├─ 둘 다 과매도 → 강한 신호
   ├─ 둘 다 과매수 → 강한 매도 신호
   └─ 한쪽만 → 섹터 이슈 가능, 뉴스 확인

[ 지지선 (장기 피보나치, 주봉) ]
□ 차트 단위: 주봉 (W) — 장기 보유 전제
□ 현재가가 ATH 또는 ATH 근처(-5% 이내)인가?
   ├─ YES → 현재 레벨 체크 스킵 (매수 신호 없음 확정)
   │        대신 "다음 매수 가격대" 미리 메모:
   │          · 2022년 저점($267) → 최근 고점($____) 피보나치
   │          · 38.2% 가격: $______ (조정 시 1차 관심)
   │          · 50% 가격:   $______ (조정 시 적극 관심)
   │          · 61.8% 가격: $______ (조정 시 강한 매수)
   │        → ATH 구간에서는 이격도/RSI가 메인 신호
   │
   └─ NO  → 2022년 저점 → 최근 고점 피보나치 그리기
            현재 가격이 어느 레벨?
              ├─ 38.2% 위:   여유, 매수 타이밍 아님
              ├─ 38.2% 터치: 1차 관심
              ├─ 50% 터치:   적극 관심
              └─ 61.8% 터치: 강한 매수 / 전략 C
```

### 2. 유동성 (5분) — FRED

```

   └─ 축소 가속? → 부정

   └─ 증가 or 0 근접? → 부정 / 한계

   YES → 유동성 근거 충족
```

## 두 가지 비중 개념 분리

### 포트폴리오 비중 (전체 자산 중)

분기 1회 리밸런싱으로 관리:

| 시장 상태 | 주식 | 현금 |
|----------|------|------|
| 과열 | 60% | 40% |
| 정상 | 80% | 20% |
| 하락 | 90~95% | 5~10% |

### 월 적립 비중 (이달 월급 잉여 중)

매월 시장 상태에 따라 결정. **percentile 기반 — 0%는 이미 매수 신호**:

| 시장 상태 | QQQ 이격도 | percentile | 매수 | CMA 적립 |
|----------|----------|-----------|------|---------|
| 극단 과열 | +25%↑ | 상위 1~3% | 0% (비중 축소도 검토) | 100% |
| 과열 | +20% | 상위 5% | 0% | 100% |
| 단기 과열/주의 | +15% | 상위 15~20% | 30% | 70% |
| **정상 (디폴트)** | **+5~+12%** | **중앙 50%** | **50% (자동이체)** | **50%** |
| 약한 관심 | 0~+3% | 하위 20% | 70% | 30% |
| **저평가 진입** | **0%** | **하위 15%** | **100%** | **0%** |
| 관심 강화 | -5% | 하위 7% | 100% + CMA 20% 인출 | -20% |
| 1차 매수 | -10% | 하위 3% | 100% + CMA 30% 인출 | -30% |
| 강한 매수 | -15% | 하위 1~2% | 100% + CMA 50% 인출 | -50% |
| 극단 (전략 C) | -20%↓ | 하위 1% | 100% + CMA 거의 전액 + 적금 | -전액 |

**핵심:**
- 비상금 0.15억은 별도 통장. 비중 계산에서 제외하고 절대 건드리지 않음.
- "정상 영역(+5~+12%)"이 대부분의 기간이므로 자동이체(50%) 디폴트로 충분.
- 이격도 0% 터치는 2~3년에 1회 오는 의미 있는 이벤트 — 적립 100% 전환.

## 시장 상태별 시나리오 (월 잉여 500만원 기준)

### Case 1: 과열 — QQQ 이격도 +18%, RSI 74 (상위 5~10%, 현재)

```
□ 매수: 0원
□ CMA 적립: 500만원
□ 자동이체: 임시 중단

이유: historical 분포 상위 5~10% 구간. 비싸게 사면 안 됨.
다음 매수 기회(이격도 0% 터치)를 위한 실탄 비축.

누적 효과:
  3개월 과열 지속 → CMA에 1,500만원 추가
  6개월 → 3,000만원 추가 (현재 CMA 0.43억 → 0.73억)
```

### Case 2: 단기 과열/주의 — 이격도 +15%, RSI 65 (상위 15~20%)

```
□ 매수: 150만원 (QQQ ETF)
□ CMA 적립: 350만원

이유: 과열 임박, 신중 모드. 자동이체 일부만 진행.
```

### Case 3: 정상 — 이격도 +5~+12%, RSI 55 (디폴트, 대부분의 기간)

```
□ 매수: 250만원 (자동이체로 처리)
□ CMA 적립: 250만원

이유: historical mean 영역. 평범한 적립식.
자동이체 설정값: 매월 1일 QQQ 250만원 매수 (50%)

→ 추세 자산은 이 구간이 가장 흔함. CMA가 너무 쌓이면 자동이체만으로
   기회비용 발생 가능 → "CMA 잔고 관리 룰" 적용.
```

### Case 4a: 저평가 진입 — 이격도 0%, RSI 40 (드뭄, 2~3년에 1회)

```
□ 매수: 500만원 (월급 전액)
□ CMA 적립: 0원

이유: 0%는 "정상"이 아니라 하위 15% 분위수의 매수 신호.
QQQ가 200MA를 터치하는 것 자체가 의미 있는 이벤트.
근거 1~2개만 충족돼도 적립 100% 전환.
```

### Case 4b: 관심 강화 — 이격도 -5%, RSI 35

```
□ 매수: 500만원 + CMA에서 100만원 인출
총 매수: 600만원
□ 5가지 근거 체크 → 2개+ 충족 시 더 적극적으로
```

### Case 5: 1차 매수 신호 — 이격도 -10%, RSI 28 (하위 3%, 5년에 1~2회)

```
□ 매수: 500만원 (월급 전액)
□ + CMA에서 200만원 인출하여 추가 매수
총 매수: 700만원
□ CMA 잔고: -200만원 변화

이유: historical 분포 하위 3%. 진짜 매수 신호. 분할 매수의 1차분.
근거 2~3개 충족 시 실행.
```

### Case 6: 강한 매수 — 이격도 -15%, RSI 25 (하위 1~2%, 5~7년에 1회)

```
□ 매수: 500만원
□ + CMA에서 1,000만원 인출 매수
□ + 적금 만기 시 일부 동원 검토
총 매수: 1,500만원+

이유: 수년에 한 번 오는 기회. 근거 3~4개 충족 시 적극 투입.
```

### Case 7: 극단 (전략 C) — 이격도 -20%, VIX 38, 실업수당 28만 (하위 1%, 5~10년에 1~2회)

```
□ 매수: 500만원 (월급 전액)
□ + CMA 거의 전액 (비상금 0.15억 제외)
□ + 적금 만기금 동원
□ + 레버리지 ETF 별도 (총 자산의 15% 이내, 손절 -15%)
총 매수: 3,000만원+

이유: 평생 자산 분기점. 근거 4~5개 충족 + 3신호(이격도/VIX/실업수당) 동시.
규칙:
  - 비상금 0.15억은 절대 건드리지 않음
  - 레버리지는 익절 +20~30%에서 일반 ETF로 복귀
```

## 자동화 + 수동 개입 운영

### 자동이체 디폴트

```
설정: 매월 1일 QQQ ETF 250만원 자동 매수 (월 잉여의 50%)
이유: "정상 모드"의 기본값. 시간 분산 효과.
```

### 수동 개입이 필요한 시점

```
□ 단기 과열~과열 (이격도 +15%↑, 상위 15~20%):
  → 자동이체 임시 중단 → 전액 CMA 적립

□ 저평가 진입 (이격도 0%, 하위 15%):
  → 자동이체 100%로 상향, 근거 1~2개 충족 시 즉시

□ 매수 신호 (이격도 -5%↓, 하위 7%):
  → 자동이체 + CMA 일부 인출 매수

□ 강한~극단 신호 (이격도 -10%↓):
  → 자동이체 + CMA 적극 인출 + 적금 동원 검토
```

### 매월 운영 흐름

```
1일: 자동이체 실행 (or 중단 결정)
   ↓
주말: 시장 체크리스트 (위 1~7 단계)
   ↓
필요시: 수동 매수 / CMA 인출
   ↓
월말: 매매 일지 작성
```

## CMA 잔고 관리 룰

장기 횡보장에서 CMA만 쌓이는 것 방지:

```
□ CMA 잔고 > 월 잉여의 6개월치 (3,000만원+)
  → 최소 50% 강제 매수 (지수 ETF)
```
